# TinkerPeek site

Static pages for the App Store listing: `index.html` (marketing URL), `privacy.html` (Privacy Policy URL), `support.html` (Support URL). No scripts, no web fonts, no third-party requests.

Published from a separate public repo with GitHub Pages (Settings ▸ Pages ▸ Deploy from a branch ▸ main / root). Keep this folder as the source; copy changes over.
